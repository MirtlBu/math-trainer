# Fonts

Open Sans (variable font, weights 400-700), downloaded from Google Fonts and served from here so the page makes no request to Google.
Subsets: `latin`, `latin-ext`, `math` (for √ ± ≥ and similar symbols). Cyrillic and other scripts are not included; if the interface ever needs them, download the matching subset from https://fonts.google.com/specimen/Open+Sans and add a `@font-face` for it in `style.css`.
